# Improvements

- ฉันเจอบัคว่าไม่สามารถเปลี่ยนภาษาได้ในหน้าแรกสุดตอน start localhost:4000
- จัดเจอว่าบาง UI ใช้ภาษาอังกฤษแทนที่จะเป็นภาษาไทย ทั้งที่ต้ังว่าเป็นภาษาไทยอยู่
- UX และการจัดเรียง UI ในส่วนต่างๆดูค่อนข้าง งง และ แย่ๆมาก
- อยากให้ยกเครื่องเรื่อง UX/UI ใหม่ทั้งหมด design ให้เข้าใจง่าย flow ไปตาม step
- UI ต้องมีความสวยงาม modern น่าใช้กว่านี้
- อย่าลืมเรื่อง responsive ด้วย
- อย่าลืมเรื่อง web accessability ด้วย
- อยากให้ปรับปรุงไฟล์ อย่าง README.md อยากให้เขียนละเอียดกว่านี้ มีคำสั่งต่างๆอะไรบ้าง เช่น ล้าง db ยังไง รันเทสยังไง seed ข้อมูลยังไง คล้ายๆ Rails dev work on this project
- อยากย้ายไฟล์ `team-retro-spec-en.md` ไปอยู่ที่ docs/specs และอัพเดทอะไรก็ตามที่ชี้ไปที่ docs นี้ให้ถูกต้อง
- อยากให้วางแผนทำ github actions ด้วย
- อยากให้ออกแบบ logo สำหรับ project นี้ เราจะได้ใช้ logo ใน app, favicon.ico และแสดงใน README.md
- วางแผนทำ documentation สำหรับ repo โดยเขียนในรูปของ Github repo website เป็นคู่มือการใช้งานอย่างละเอียดสำหรับ developer และ users
- จากข้อก่อนหน้า ตรงนี้ไม่แน่ใจว่า comments docs สามารถ generate ออกมาเป็น docs สำหรับ dev ได้เลยไหม แต่เราก็ต้องทำ document การใช้งานสำหรับ user อยู่ดีว่าเล่นแอพนี้ยังไง
- คู่มือการใช้งานควรมีรูปประกอบ
- สำหรับคู่มือ dev อยากให้การแอพตอน deploy จริงสามารถ support postgreQL database ได้ด้วย อาจจะต้องสำรวจและปรับโค๊ด
- สำหรับคู่มือ dev อยากให้เขียนคู่มือการ deploy ลงบน cloud services ต่างๆ ที่เป็นที่นิยมในหมู่ elixir dev
- ไม่แน่ใจว่าแอพนี้สามารถ deploy บน coolify ได้หรือไม่ ถ้าได้ เขียนวิธีการให้ด้วย
- วางแผนการทั้งหมดอย่างละเอียดสำหรับทำสิ่งที่ list ไว้ตามนี้ จากนั้นเขียนเป็น markdown ไฟล์ลงใน docs/plans เป็นภาษาอังกฤษเท่านั้น
- ไฟล์ที่เขียนใน docs/plans จะต้องผ่าน markdownlint โดยไม่มี warnings/errors ใดๆและใช้ default rules เท่านั้น ห้าม override หรือดัดแปลงเด็ดขาด
- เขียนแค่แผนก่อนยังไม่การ actions จริงๆอย่างใด
- ก่อนเสร็จให้ audit แผนทั้งหมดอีกรอบอีกครั้งเพื่อเช็คว่ามีอะไรตกหล่นไหม
- เมื่อเขียนเสร็จแล้วให้ commit และ push ขึ้น repo ได้เลย
